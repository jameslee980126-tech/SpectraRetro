# Experiment configuration

The two complete workflow configurations are [known-class/configs/full.json](../experiments/section_4_results/4_1_benchmark/known-class/configs/full.json) and [unknown-class/configs/full.json](../experiments/section_4_results/4_1_benchmark/unknown-class/configs/full.json). They specify sampling settings, checkpoint paths and Python environments.

[checkpoints.json](checkpoints.json) and [baseline_checkpoints.json](baseline_checkpoints.json) identify shared/available selected weights. The [baseline configuration directory](baselines) contains method-specific settings. Each [experiment record](../experiments/manifest.json) also lists its configuration or saved training metadata.
