# Unknown-class SpectraRetro

When the reaction class is withheld, SpectraRetro predicts centers on the product graph, completes the synthons and ranks the assembled precursor sets using their chemical features and occurrence frequency. [Reaction-center model](reaction_center/) · [Completion](completion.py) · [Ranking](ranking.py).

Run the §4.1 benchmark from the repository root.

```bash
python src/spectraretro/unknown-class/run.py
```
