# Structural errors in the top-ranked precursor set

[Figure 3a,b](figures/figure_3_case_studies_combined.png) · [Figure S3a](../../supporting_information/s5_agent_cases/figures/figure_s3_case_studies_additional.png)

Figure 3a,b shows a donor identity mismatch and omission of a Boc protecting group. Figure S3a shows halogen substitution on the wrong partner. The case records identify each reference and predicted structure. The population tables cover all 9,250 full-test reactions and allow the selected cases to be interpreted alongside reaction-center and precursor-level errors.
